    What to notice

    • The Network tab shows one /step4/stream request, not four. Browsers limit open connections per host (6 over HTTP/1.1), so one stream with named events scales better than one stream per widget.
    • The event name picks the listener; the listener picks how the data goes in. The gauges replace their content (innerHTML), the activity list prepends (insertAdjacentHTML('afterbegin', …)).
    • The orders event is plain text, not HTML, so it goes in with textContent.
