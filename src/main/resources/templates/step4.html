Step 4: A live dashboard

One stream feeds the whole dashboard. The server sends four kinds of events (cpu, memory, orders, log), and each element subscribes to the name it cares about.

    What to notice

    • The Network tab shows one /step4/stream request, not four. Browsers limit open connections per host (6 over HTTP/1.1), so one stream with named events scales better than one stream per widget.
    • sse-swap picks the event name; hx-swap picks how the data is inserted. The gauges replace their content, the activity list prepends.
    • The orders event is plain text, not HTML. htmx swaps whatever data arrives.
    • An element can listen to several names: sse-swap="cpu,memory".
