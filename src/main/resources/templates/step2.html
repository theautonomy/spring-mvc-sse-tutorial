Step 2: A ticking clock

A stream that stays open. The server pushes a named time event every second, and a few lines of JavaScript put each event's data into the page.

--:--:--


    


    

        
What to notice

        
    
            
  • The whole client is one EventSource and one addEventListener('time', …).
                Named events never reach onmessage.
    • 
            
  • The emitter has a 60 s timeout. Wait a minute: the log below shows the stream end and the browser reconnect.
                Without an explicit timeout, Tomcat would end it after 30 s.
    • 
            
  • Close this tab and watch the server log: the next send fails, onCompletion runs,
                and the sending thread stops. Without that cleanup, every visitor would leave a thread behind.
    • 
            
  • Open the page in two tabs: each tab gets its own stream and its own thread.
    • 
        

    


    

        
Try it with curl

        
curl -N http://localhost:8080/step2/stream

        
Every second: event:time and data:12:34:56. Press Ctrl+C to leave, and watch the server log.
