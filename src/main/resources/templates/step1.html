Step 1: Hello world

No htmx yet. This page uses the browser's built-in EventSource to read /step1/stream. The server sends one message and a close event, then ends the response. 


    


    

        
What to notice

        
    
            
  • Naive: the message number keeps going up. When the server ends the response, EventSource
                treats it as a dropped connection and reconnects about every 3 seconds. SSE has no "end of stream" message.
    • 
            
  • Handles "close": the page listens for the named close event and calls es.close(),
                so there is exactly one message. Ending a stream is something client and server agree on.
    • 
            
  • Unnamed data arrives in onmessage. Named events need addEventListener('close', …).
    • 
            
  • Watch the server log: every reconnect is a new request, connection #N.
    • 
        

    


    

        
Try it with curl

        
curl -N http://localhost:8080/step1/stream

        
You'll see the raw format: data:Hello, world #1, a blank line, then
            event:close and data:bye. A blank line ends each event.
