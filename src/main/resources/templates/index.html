Server-Sent Events with Spring MVC and htmx

Server-Sent Events (SSE) let the server push data to the browser over one long HTTP response. Each step below is a small working example that builds on the one before it. TUTORIAL.md in the repo explains every step in detail.

  1. Step 1: Hello world

    The SSE wire format, SseEmitter, plain EventSource, and why the browser keeps reconnecting.

  2. Step 2: A ticking clock with htmx

    A long-lived stream, sse-connect and sse-swap, emitter timeouts and cleanup.

  3. Step 3: Progress of a long task

    POST starts a job, the response opens its stream, HTML fragments as events, sse-close, errors.

  4. Step 4: A live dashboard

    One stream, many named events, each updating its own part of the page.

  5. Step 5: A chat room

    Broadcast to many tabs, dead-client cleanup, heartbeats, event ids and catching up after a reconnect.

  6. Step 6: Ask the user

    Two-way flow: the job pauses, asks a question over SSE, and continues when the answer is posted.
